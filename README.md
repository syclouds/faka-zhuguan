# 法考主观题速记 · 微信小程序

一款面向法考主观题考生的**考点记忆 + 论述题背诵**小程序。核心是「考点卡片 + 采分点默写 + 艾宾浩斯复习队列」，帮你在考前把该背的采分点真正写出来。

- 技术栈：微信原生小程序 + 云开发（可选）
- 内置内容：**88 个结构化考点 / 8 套论述模板**，覆盖习近平法治思想、刑法、刑诉、民法、民诉、行政法、商法七科
- 包体积：全量源文件约 400KB（图标 11KB + 考点数据 160KB + 页面 172KB），远低于 2MB 限制；考点数据已放分包 `pages-study`，主包保持轻量

## 二、核心功能说明

| 页面 | 功能 |
|---|---|
| 考点（首页） | 考试倒计时（可自定义日期）、今日待复习/待新学数量、连续打卡、七科章节导航、S级必考速览、搜索入口 |
| 背诵 | 四个 Tab：今日 / 错题 / 收藏 / 全部；可调每日新学上限 |
| **背诵卡** | ① 先只显示考点标题，自问自答 → ② 翻卡看核心+采分点+法条+易错提示 → ③ **采分点默写**（关键词挖空输入，自动判定命中）→ ④ 三档掌握度标记 |
| 论述 | 按主题筛选模板，卡片直接展示答题框架；「开始背诵」进入逐步揭示的框架背诵模式 |
| 论述详情 | 框架 / 万能金句（勾选已背）/ 可替换槽位 / 示范段落 / 失分点 / **答题草稿练习**（可一键生成框架草稿） |
| 我的 | 掌握度分布、近7天学习柱状图、背诵设置、错题本、收藏、自建考点、云同步、重置数据 |

### 复习算法
- 掌握度三档：`没记住(0) / 有点模糊(1) / 记住了(2)`
- 三档分别对应不同艾宾浩斯间隔数组（见 `utils/constants.js` 的 `REVIEW_INTERVALS`）：
  - 没记住：0,1,1,2,4,7,15 天（下次立刻重现）
  - 模糊：1,2,4,7,15,30 天（原地踏步不进阶）
  - 记住了：3,7,15,30,60 天
- 标记「没记住」自动进入错题本；标记「记住了」自动移出
- 连续打卡自动计算，跨天自动重建今日队列

## 三、接入云开发（多设备同步）

本地功能不依赖云开发。若要多设备同步进度：

1. 开发者工具 → 云开发 → 开通（选择按量付费，免费额度足够个人使用）
2. 在环境列表复制 **环境 ID**，打开 `miniprogram/app.js`，把 `initCloud()` 中的
   `env: wx.cloud.DYNAMIC_CURRENT_ENV` 改为 `env: '你的环境ID'`
3. 右键 `cloudfunctions/login` → 上传并部署（云端安装依赖）；同样部署 `progress`
4. 云开发控制台 → 数据库 → 新建两个集合：`users`、`study_progress`

**安全规则**（两个集合都设，务必不要设成"所有用户可读写"）：
```json
{
  "read": "auth.openid == doc.openid",
  "write": "auth.openid == doc.openid"
}
```

5. 建议索引：`study_progress` 建 `openid` 单字段索引（唯一）；`users` 建 `openid` 单字段索引（唯一）

部署完成后，首页和「我的」页会自动走云同步；「我的 → 立即同步进度」可手动触发。

> 云函数中所有读写都以 `cloud.getWXContext().OPENID` 为数据归属，前端无法伪造他人 openid；合并策略按 `lastAt` 取较新记录，避免旧设备覆盖新进度。

## 四、内容扩充方法

### 新增考点
在 `miniprogram/data/study-xxx.js` 中按以下结构追加对象即可，无需改任何页面代码：

```js
{
  id: 'crim-17',              // 全局唯一，建议 科目前缀-序号
  chapter: '重点罪名',         // 章节名，同名字段自动归为同一章节
  title: '考点标题（卡片正面）',
  level: 'S',                 // S必考 / A高频 / B常考 / C了解
  core: '一句话核心，答题定调用',
  points: [
    { k: '采分关键词', v: '展开表述（默写时挖空的是 k）' }
  ],
  clauses: ['《刑法》第xx条'],   // 法条依据
  trick: '易错提示'            // 显示在卡片底部的黄色提示框
}
```

新增科目：在 `utils/constants.js` 的 `SUBJECTS` 中加一项，并在 `data/index.js` 的 `RAW` 中注册对应文件。

### 新增论述模板
在 `data/essay-templates.js` 中追加，字段：`topic / title / level / frame[] / phrases[] / fill[] / sample / trap`。

## 五、内容维护提醒

- 本库内容依据公开的现行法律法规与司法解释整理，**仅供备考参考**；法考大纲与法规会逐年更新（如《公司法》2023年修订、《行政复议法》2023年修订均自2024年施行），请在使用前核对最新版本。
- 涉及具体分值、考试日期、报名政策等，请以司法部官方公告为准。
- 建议每轮备考前把 `level: 'S'` 的考点过一遍，确认法条序号与表述无误。
