## 2. 分科对账

### 2.1 法治思想（rule-law）

- 考点卡：12（存量 rule-01~12）+ 5（补丁 rule-13~17）= **17 卡**（目标 ≥16 ✅）
  - rule-13 形成发展的"三个逻辑"与鲜明特色
  - rule-14 在法治轨道上全面建设社会主义现代化国家
  - rule-15 共同推进、一体建设（法治国家/政府/社会三者关系）
  - rule-16 法治保障作用（"经政文社生"五个保障）
  - rule-17 重大关系处理（政治和法治、发展和安全）
- 案例卡：4 案例 7 问（营商环境 / 枫桥经验 / 司法责任制 / 依宪治国），qType 以 essay、open 为主
- 口诀卡：未设置（法治思想以论述逻辑为主，短口诀易失真，设计性取舍）

### 2.2 刑事诉讼法（crim-proc）

- 考点卡：15（存量）
- 口诀卡：**76 条**，覆盖 管辖与回避(7) / 辩护与代理(7) / 证据(9) / 强制措施(8) / 侦查(7) / 起诉(6) / 一审(8) / 二审(7) / 死刑复核与执行(5) / 特别程序(8) / 认罪认罚从宽(4)

- clauseIndex 全部走 string[]（U-2），例：`['刑诉法 54', '刑诉法 56']`

## 4. 手写补丁操作备忘（rule-13~17）

或将 rule-13~17 五卡对象重新粘贴至数组末尾（完整对象见本仓库 git 历史，均在 17 卡版本中）。

## 5. 合规说明

- 全部新增条目（口诀短句、案例案情、参考答案、采分点、模板结构）均为原创整理：
  - 口诀短句为自创助记词；展开内容为对现行法律法规规则的**自述归纳**；
  - 案例案情为自编教学情境，人物情节均为虚构；
  - 法治思想条目为对公开官方表述（如"十一个坚持"清单）的自述归纳与记忆整理；
  - 法条号为客观事实信息（现行有效法律条文序号）。
- 每个数据文件头部均带合规声明；App 内三处 DISCLAIMER 常量展示（首页/关于页/案例页，T04/T05 落地）。
- 原始 PDF 抽取文本位于 raw/（已被 .gitignore 排除），仅作为本地校对参考，不构成发布物。
